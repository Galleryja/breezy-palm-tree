# Brand font

Drop **`CloisterBlack.ttf`** in this folder (exact spelling, no spaces).

Source: https://www.1001fonts.com/cloister-black-font.html — Dieter Steffmann's
2001 digitization, free for personal and commercial use, redistribution and
modification allowed. Keep the license file that ships in the download next to
the font so the terms travel with the repo.

The `@font-face` rule in `app/globals.css` points here. Until the file exists
the browser falls through to UnifrakturMaguntia, an open-licence blackletter,
so the site never breaks — it just isn't wearing the real mark yet.

The original design (Morris Fuller Benton, 1904) is long out of copyright.
